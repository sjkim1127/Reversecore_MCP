# Development dependencies are sourced from the unified lock file.
#
# requirements.txt is generated from pyproject.toml with all extras enabled:
#
#   uv pip compile pyproject.toml --all-extras -o requirements.txt
#
# It therefore already includes the `dev` extra as well as the runtime feature
# extras. Keeping this file as a thin include prevents a second, stale lock from
# overriding pinned runtime dependencies such as FastMCP during CI installs.
-r requirements.txt

# Install the transparent CI-only pip-audit policy wrapper. It delegates to the
# official pip-audit CLI and adds only the temporary Pillow advisory exceptions
# tracked in issue #146 when CI=true; local audits remain strict.
./ci/pip_audit_policy
